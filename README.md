Entrants send exactly one letter, A to Z, the initial of the word that describes their day. A judge compares letters two at a time on which hidden word feels more vivid, funnier or truer, and the best letter takes the reward.

This entry's letter is **U** — for *unhinged*: a day that went off the rails. Funny the moment you hear it, honest about a strange day, and a word whose every near neighbour (unproductive, up-all-night, under-caffeinated) points the same way.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes exactly one letter to `out/entry.txt` (1 byte, no trailing newline), deterministically.
